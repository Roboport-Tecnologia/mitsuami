mitsuami 2.3.0 lets an app run without windows, so it can wait in the background for a notification's click or another process's request and open a window only then.

## All platforms

- **An app can run without windows**, with `App::runs_without_windows()`: it starts with none if it likes, opens them as it needs, and keeps running when its last one closes, because an app that waits for a notification's click or another process's request has nothing to show until then, and a click only reaches the process that posted the notification.
- **`quit()` ends the app** once the current turn is done, with windows open or not, without asking them first. An app that runs without windows ends this way.
- **`examples/background.rs` shows it**: it starts with no window, posts a notification, and opens its window when it's clicked.
