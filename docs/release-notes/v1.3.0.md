mitsuami 1.3 puts WinUI windows on Mica, as Windows 11's own apps are. It's a drop-in update from 1.2, with no API changes.

## Windows (WinUI)

- **Windows are on Mica.** Each window gets a `MicaBackdrop`, which Windows tints from the desktop wallpaper, as WinUI's guidance has it for primary windows. The window's root and content host are transparent over it, and a sidebar's pane sits on it as in Settings. Mica shows its solid colour where it can't be drawn: an inactive window, Windows 10, or transparency effects turned off.
- **Mica Alt behind document tabs.** A window with document tabs in its title bar is on Mica Alt, as File Explorer's tabbed title bar is.
- **A window keeps its size when its menu bar is rebuilt.** The bar is rebuilt after every menu closes, and each rebuild used to put the window back to the content size the app last asked for, even after the user had resized it. That size is now applied again only when the bar's height changes.
