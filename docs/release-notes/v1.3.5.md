mitsuami 1.3.5 keeps a macOS window in place when a dialog goes up on it as it opens.

## macOS (AppKit)

- **A sheet waits for its window.** An alert or file panel asked for on a window that hadn't been shown yet began its sheet at once, and AppKit put the window in the screen's bottom-left corner: it jumped to the centre with the sheet and back to the corner when the sheet ended. The dialog now waits until the window is shown, then goes up on it.
