mitsuami 2.2.1 keeps a WinUI `GpuSurface` on its own page, so it no longer shows over a tab or pane it isn't in.

## Windows (WinUI)

- **A `GpuSurface` hides while the `Tabs` page or `Split` pane holding it is hidden.** XAML collapses a page that isn't chosen and a hidden pane but keeps them loaded at their size, and the surface is a child window outside XAML's tree, so it stayed over the page shown: SourceGit's code view from another page sat a little off above that page's own editor, and took none of its keys.
