mitsuami 1.3.3 lets folder dialogs on macOS make a folder.

## macOS (AppKit)

- **Folder dialogs have New Folder.** AppKit's open panel leaves it off, so a folder dialog couldn't make the folder it was asked to choose, which GTK's, Qt's and Windows' folder dialogs all offer. A panel that opens folders now lets the user make one; a file panel keeps AppKit's default.
