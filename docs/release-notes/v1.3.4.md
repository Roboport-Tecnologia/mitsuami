mitsuami 1.3.4 fixes GTK windows the app resizes before they're shown.

## Linux (GTK)

- **A window resized before it's shown lays out at its new size.** A resize before the window's first map wasn't reported, so the window opened at the new size with its content laid out at the old one.
- **A sidebar change no longer undoes a resize.** Adding or removing a sidebar, or changing its width limits, kept the last allocated content size rather than the one a resize was taking the window to, so the two together undid the resize.
